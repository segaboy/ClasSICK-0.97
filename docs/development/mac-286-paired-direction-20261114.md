# Owner direction: Mac and 286 paired release

2026-11-14, SRC-0608. The owner pauses x64 work and replaces the PC x64 target of the next paired release with a native 286 target. The initially requested BootHush-only test environment, active BootHush and Not Super Tilt Bro work, evidence sharing, clean-room restrictions and separate release approvals continue. This direction supersedes ADR-0078's Mac/x64 pairing and the x64-specific part of paired-native-preview-2 for the next release; their historical records and published releases remain unchanged. It does not imply a release has been prepared or approved.

The existing interactive-preview goal is retained: on each target a user can move an original cursor, drag and release one original window, and toggle its content once per press without trails. The same semantic sequence and original 512x342 logical image must match on both native targets. The 286 target begins with the already identified PC/AT 5170-class 6 MHz, 640 KiB and EGA profile; a keyboard-driven pointer is the documented initial input candidate, not yet an implemented or physically qualified replacement for a mouse. Its EGA output centers the unscaled logical canvas at (64,4) in 640x350. The input mapping, adapter, firmware/boot and exact media contracts must be reviewed and implemented before a release candidate can be asserted. No PC version, reduced-scope waiver, hard-disk installation claim or application compatibility claim is assigned here.

Release work still requires source/specification and original fixture provenance; independent state and normalized-pixel checks; actual original Mac and 286 candidate builds, memory and stack/segment budgets; headless BootHush observations; appropriately separated device-injection, GUI and human results; required physical and review gates; and a source-matched package, notices, setup instructions, checksums and separate owner publication approval. Failed prior observations remain recorded. Existing E1–E4 categories remain distinct; scheduled keyboard input is not a physical or human test. Unmet or inapplicable checks require explicit disposition, not silent substitution.

At direction time the 286 work consists of original 16-bit diagnostic boot and segmented-memory models exercised in BootHush; it is not a production 286 boot, graphical window, installer or release candidate. The Mac model can perform bounded injected drags but fast input, physical and human qualification remain unresolved. The 286 system's production loader, native renderer/input integration, parity and release tests remain work. [Earlier diagnostic evidence](boothush-paired-20261114.md) is not reclassified.

BootHush and the port continue where they expose Mac/286 hardware and test gaps or support the product; no game-derived implementation, emulator implementation or protected material is admitted as a ClasSICK implementation input by this decision. BootHush remains the only emulator; unattended tests must be headless, bounded and reproducible. Reference systems, physical trials and publication retain their separate authority requirements.
