## Suggested story

We are tracing mouse movement through the system rather than relying on a
successful call or a green build. Today's offline work produced a reproducible
experiment:two observations can have identical start/end phases yet imply
different motion when the intermediate states are missing. In one original
model example,three forward phase edges produce−1 X unit when each is observed;
the endpoints alone look like a reverse step and produce+1. A complete cycle
can also leave no endpoint change. These are model units,not measured pixels.

Both pinned host compilers reproduced1664 cases each with identical CSV output.
The useful result is specific:our current Mac loss record omits the previous
PB4/PB5 bits. Three missing-bit assignments fit the recorded rejection,so the
next diagnostic needs the complete previous phase endpoint. The study does not
identify the physical fault or justify changing the timer or mouse direction.

The current native Mac experiment uses23772 bytes of a65536-byte ROM file—about
23.2KiB of64KiB. The PC boot application is180KiB;its64MiB boot disk is a container.
These are current scene artifacts and different size measurements,not a forecast
for completed System1,an application suite or the286 installation.

Both Windows and Mac CI pass for the latest implementation checkpoint ebfbfb9.
Usable mouse motion and dragging still block the paired release. Research
continues while the desktop trials remain paused.
