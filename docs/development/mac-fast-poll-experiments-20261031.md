# Mac fast-poll experiments

2026-10-31; SRC-0581 / TEST-0128. Four scratch-only experiments based on public revision `237bfd84b1b489c8cff94ba274215e7231dae3cd` tested faster polling candidates. None changes a repository source file or the existing 16-NOP hardware contract. Each original 64 KiB ROM was compiled with the project's pinned 68000 compiler in an isolated workspace, passed the builder's native code checks, and booted in a separate isolated Snow 1.5.0 Early128K session without disks or shared folders. The own MWP1 v2 trace was located at `0xBAC` from each build's linker map. The sessions were externally stopped; this does not imply guest shutdown.

- **Shorter guard:** an unadopted eight-NOP guard, ROM SHA-256 `735861beecf8389a4a6c653c3890c9a9aee0673c3038c1c795a0da6d7f6ff07d`. The paused trace showed 55,101 services, 29 baselines and 6,437 losses; the retained first reason was 5, timer recurrence. No deliberate viewport movement was part of this idle check. The existing documented contract still requires 16 NOPs.
- **Combined callback:** retained all 16-NOP guards and moved the existing A/B reset writes into the native paired-read callback, ROM SHA-256 `e6d1d76b1c7c5318e720c5dc07637a2382d7df7832f86a57318488fc18f096b3`. The original generated pair code was checked for the intended A/B writes followed by PB/A/B/PB/A/B reads and six 16-NOP guards. The paused trace showed 37,518 services, four baselines and 4,743 losses; the retained first reason was 5. This changes the pair-only callback contract in scratch and is not an adopted implementation.
- **Intermediate rate:** the same combined-callback idea with the full guard and an experimental divisor of 8, ROM SHA-256 `7705e4c204856f826f705214150c3d16eea98c9a7b5241caa0ca087f3715affc`. The paused trace showed 21,531 services, 1,291 baselines and 1,291 losses; the retained first reason was 5. It was not moved on to a motion test because the idle check already showed loss.
- **Less frequent diagnostic copying:** the intermediate candidate with its foreground interrupt-masked trace copy performed once per 64 foreground turns, ROM SHA-256 `53e6f1eb7ca74ab60de3add9184106d16f9809fc4faa8148cfdaabbfd09a7b59`. The paused trace showed 28,864 services, 1,598 baselines and 1,598 losses; the retained first reason was 5. The snapshot may be up to 63 foreground turns stale. This change did not remove idle losses and is not adopted.

The loss field retains only the first reason; the totals do not classify all losses. Different elapsed intervals prevent comparison of raw totals as a performance benchmark. Neither test established a usable pointer, dragging, physical hardware behavior or release readiness. The experiments rule out these particular candidates as ready fixes, not every approach to timer or interrupt handling. Source snapshots, build manifests and test ownership receipts remain in `C:\ClasSICK\mac-fast-guard-probe-20261031-a`.
