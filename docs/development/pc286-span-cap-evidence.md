# 286 capability/borrow qualification

2026-10-30; baseline 833df56bcf431b3f2032e7e8b1f4fdb6f269daa0. SRC-0574, SPEC-0087, IMPL-0098, TEST-0122. The owner-approved original 286 contribution is integrated as an isolated model after the separate slice A qualification. The preserved r4 intake and role restrictions remain in SRC-0558; the unrelated CLEANROM and affected Mac/68000 lanes are not adopted. This is an original engineering model, not historical Macintosh behavior. Original intake files remain unchanged outside Git; their author supplied the two implementations and two author tests. The lead supplied a separate literal oracle and integrated the CMake and compiler profiles.

Original SHA-256: `span-cap.c` 9f563b8d27919f4126a2c73067542583179f44e0202884cc77e2fd4ac9b4b1f5; `span-cap.h` 99578609f3d65577a304ad28102e0e5aff05d1f88bcf11179641c2a56786d669; `pc286-span-cap.c` a6b9a41058b9ea56c6e89da2f6f851e1074d4733b20ecb3eda9559cf5ceb58a5; `pc286-span-cap-parity.c` 45e2a0b97dae5d1de2b950e2b956671ca7f896db762ccf62817f6ab9900d5ca1. The contract's status and heading were updated on adoption; its author-evidence section remains explicitly attributed, not a project test claim.

Four Windows host profiles (GCC x64, GCC i686, Clang x64, and Clang x64 with ASan/UBSan) each passed the author capability and guest.c-parity suites and the lead-authored oracle: 12 passes. The author tests report 48,780 checked chunks and 8,000 window comparisons, including 1,889 borrowed windows. The independent oracle checks a split native span, write permissions, unchanged outputs after refusal, stale capabilities after rebind/new owner lifetime, exhausted rebinding, release, and retained backing bytes. Three separately compiled scratch defects—exposing a writable pointer for read-only requests, ignoring a generation change, and ignoring requested rights—each failed the independent oracle at its corresponding assertion. This is fault sensitivity for those cases, not a proof of completeness.

The integrated pinned Open Watcom profile compiled four unlinked 80286/USE16 closure objects (mc/ml with od/os), with no unresolved imports. Two near-data profiles failed at the existing span-bind far-pointer assertion. Neither link nor target execution occurred. CMake built and ran all three newly integrated tests on GCC x64. No other AI worker was used for this slice.

Limitations: this model relies on caller-managed lifetimes, exclusive stability, real backing extents, nonaliasing and correct pointer provenance. It does not yet provide a production memory owner, hard-disk installation, physical memory discovery, measured cost, target ABI/stack proof, 286 boot or native application support. Repeated binding validation is not a performance qualification. Slice C remains deferred. The Mac mouse and PC GUI dragging gates remain open; this work does not make the paired release ready.
