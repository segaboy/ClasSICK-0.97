# ClasSICK ROM 0.1.0-alpha.1 - draft release notes

**Unpublished candidate. Proposed tag: rom-v0.1.0-alpha.1. No tag target selected.**

This independently authored 64 KiB ROM boots its own native kernel and runs an
original 68k application through the resource/CODE loader. It captures D0=97 and
the application's 0x5A5A5A5A write, retires its image, and displays the result.
Native counter updates preserve the rest of the scene. The version belongs to
this ROM release track; ClasSICK 0.97 remains the compatibility-target name.

## Important limits

This is an early firmware/application prototype. It has no complete Toolbox,
guest drawing/window/event support, desktop or filesystem/disk-System boot.
Guest execution uses a selected instruction subset and a narrow one-entry,
one-segment profile. It is not a drop-in replacement for an original Apple ROM.

Some automated mouse events were not visibly credited; exact delivery cause and
event attribution remain unresolved. The rendering observation qualifies captured
updates, not all-click reliability, human input or calibrated performance.
Real Macintosh operation and complete 128K OS feasibility remain unverified.
Original System 1 disks on this ROM and our System on a supported original Apple
ROM remain required and untested. Historical 0.97 identity, parity, three-edition,
B2 and human provenance gates are not closed by this candidate.

## Planned review bundle

The local preparation tool supplies the versioned original ROM, exact build and
qualification manifests, these notes, GPL-3.0-or-later project notices, pinned
original-source links and SHA256SUMS.txt. It marks the directory DRAFT.
Compiler executables, Apple firmware/media/assets, private research, HQ contents
and emulator software are excluded. No System software is bundled.
