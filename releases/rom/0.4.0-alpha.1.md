# ClasSICK ROM 0.4.0-alpha.1

Paired experimental native Macintosh 128K/68000 ROM with a movable original window, restored cursor,
click counter and content pattern. Shared logical pixels match across both
targets in automated BootHush checks. System software remains unreleased.

See the [paired qualification receipt](../../docs/development/paired-release-20261117.md),
[setup and limits](../TRYING-mac286-20261117.md), and
[owner release disposition](../paired-native-preview-2-release.json).
This experimental publication does not close human responsiveness, physical
hardware, complete System compatibility or independent provenance review.
