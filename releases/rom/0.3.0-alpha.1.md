# ClasSICK ROM 0.3.0-alpha.1

Experimental firmware preview. The surrounding approval record determines publication status; these download notes do not authorize publication.

- Component tag: `rom-v0.3.0-alpha.1`
- Component version: 0.3.0-alpha.1
- Type: an experimental, original native drawing preview. It is not System 1, not a desktop and not a hardware release.

## What it is

An original 64 KiB ROM for Macintosh 128K-class emulation. It draws its own black-and-white 512x342 scene: a ring with rails, six phases, the result 0097 and an input counter. It needs no Apple ROM, disk or software, and contains no Apple code or assets. The paired PC preview (`pc-v0.1.0-alpha.1`) draws the same scene with the same portable C compiled to native x86-64 code.

## Assets

- `classick-rom-0.3.0-alpha.1-mac128k.rom`: the ROM image.
- `classick-rom-0.3.0-alpha.1-demo.zip`: the ROM, README.txt (how to try it), RELEASE.txt (these notes), COPYING, SOURCE.txt and SHA256SUMS.txt.
- `classick-rom-0.3.0-alpha.1-source.zip`: the complete source at the compiled revision.
- `SHA256SUMS.txt`: checksums for the three files above.

No emulator or compiler is included.

## What was checked

- In Snow's Early Macintosh 128K model with 128 KB, a person clicked twice and both clicks were counted.
- CI covered 3150 tests across 11 profiles, and the Mac ROM was unchanged.

## Known limitations

These are not qualified. Each one needs the owner's explicit acceptance:

- Isolation from persistent Snow preferences.
- Full Macintosh 128K behaviour beyond Snow's Early 128K model, mini vMac and real Macintosh hardware.
- Both required boot directions remain untested: original System 1 disks on the replacement ROM, and a future replacement System on a supported original Apple ROM. No System release exists yet.

## Rebuilding from source

On Ubuntu 24.04 with Python 3 and dpkg-deb, from the unpacked source archive. Use new paths that do not exist yet:

    python3 scripts/Setup-M68k.py --output NEW_TOOLS
    python3 scripts/Build-LoadedAppROM.py --outline-drawing --tool-root NEW_TOOLS/root --output NEW_ROM

Then compare `NEW_ROM/Os-a/classick-loaded-app.rom` with the ROM hash in SHA256SUMS.txt. Setup downloads hash-pinned compiler packages; neither script runs an emulator.
