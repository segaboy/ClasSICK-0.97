# ClasSICK ROM 0.2.0-alpha.1 - experimental prerelease

This ROM adds the loaded application's first drawing calls and a shared
monochrome product scene with original monitor/C branding. The same portable
renderer now serves the Mac ROM and the native-PC development build. This
release distributes the Mac ROM; System software remains unreleased.

[Download and Snow setup](TRYING-0.2.0-alpha.1.md).
Tag: `rom-v0.2.0-alpha.1`. [Publication receipt](0.2.0-alpha.1-publication.json).

## Changes since 0.1.0-alpha.1

- An original40-byte68k application executes through the resource/CODE loader
  and calls the selected PaintRect and EraseRect APIs. Its fixed128x64 drawing
  port produces the visible hollow rectangle; D0=97 and six completed phases
  supply the result display. The CODE handle is retired after execution.
- One portable512x342 monochrome scene supplies the branding, APP/097,
  drawing panel, six phase marks, progress boxes, result and input counter.
- The Mac native mouse-counter path remains; delivery and human input remain
  unqualified. The PC counterpart centers its logical512x342 image in its
  reported framebuffer, and is distributed separately from this ROM release.

## Scope and downloads

This remains an embedded original application/firmware prototype. It has no
complete Toolbox, general guest QuickDraw, desktop or filesystem/disk-System
boot. Guest execution uses a selected instruction subset and narrow one-entry,
one-segment profile. It is not yet a drop-in replacement for an Apple ROM.
Real Macintosh operation, full128K OS feasibility, reliable input and both
System1/ROM boot directions remain unverified. Historical identity, edition/
parity/B2, native-app and human provenance gates remain open.

The demo ZIP includes the exact ROM, Snow/rebuild instructions, build and boot
records, license/notices and checksums. The complete matching original source
ZIP, standalone ROM and outer SHA256SUMS.txt are separate downloads. No ROM
bytes were patched for versioning. No System disk, Apple/Microsoft payload,
manual, private research, HQ content, compiler or emulator is bundled.

[Independent release policy](../README.md). Earlier release bytes/tags remain immutable.
