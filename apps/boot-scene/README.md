# Original boot test scene

SPEC-0009 / ADR-0013. A deterministic geometric pattern (corner markers, a panel,
eight bars and a sixteen-segment progress track) rendered band by band through the
core surface API, with at most 64 KiB of arena staging. It is an original test
image for native presentation, not a Macintosh screen, icon or startup picture.
Hosted tests compare every pixel with an independent point classifier.
