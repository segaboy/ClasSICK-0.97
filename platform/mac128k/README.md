# Macintosh 128K platform

SPEC-0018 / IMPL-0022 provides original ROM startup, VIA VBL/mouse polling,
loaded-image CRC and an original monochrome scene. Build/hosted verification is
documented in [Mac ROM evidence](../../docs/development/mac-rom-evidence.md).
No Apple ROM fallback, copied resources, System 1 services or full OS parity.
Snow is a scoped black-box platform; emulator results and real hardware are
separate. The complete 128K feasibility gate remains open.
