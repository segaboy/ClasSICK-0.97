# System 1 compatibility personality

Current hosted foundation: SPEC-0023/0025/0027 implements selected memory/register
services and typed patches; SPEC-0029 adds bounded typed stack builtin dispatch
and root session ExitToShell. The caller supplies reviewed immutable routine
records; synthetic conformance records are not a historical manager catalog.
Installed stack patches, loader continuations, retained pointers and broader
manager callbacks remain explicit refusals. No default boot integration or heap
teardown; exact-version historical limits stay at the compatibility boundary.
See [manager ownership](../../docs/architecture/system1.md).
